# SOVEREIGN CONSEQUENCE Master Blueprint

## Simulation
Factions; population/civilians; territory; resources/economy; construction; units/squads; logistics; diplomacy; intelligence; public sentiment; institutions; policy/doctrine; influence; consequences; campaign events; morality represented through multidimensional outcomes rather than a single good/evil scalar.

## Combat/RTS
Selection/commands/formations/pathing/cover/objectives/unit abilities/production/logistics/fog-of-war. Strategic decisions feed tactical state and vice versa.

## Unreal
RTS/RPG Unit Template primary RTS accelerator. OverCrowd for civilian/population scale after performance evaluation. Squad AI for tactical autonomy. Building System for construction. Narrative Pro owns authored events/choices. Ultra provides shell/shared systems. Reconcile all duplicate unit stats/save/network systems into canonical SOVEREIGN schemas.

## Forge mode
Scenario/map/rules/faction/unit/objective editor with validation and sandboxing. Creator content uses data-driven definitions.

## AXIOM
Simulation core should be engine-neutral where practical; AXIOM renderer/runtime consumes canonical simulation state. This game is a major AXIOM scale/AI benchmark.

## XYRA
Deterministic simulation tests; economy exploits; pathing stress; crowd performance; save/replay; AI deadlocks; consequence consistency; multiplayer authority if enabled; creator-content validation; accessibility/UI density.

## Delivery
Simulation kernel → RTS controls → economy/building → influence/consequence → vertical scenario → diplomacy/civilians → campaign scale → Forge → multiplayer if approved → AXIOM.
