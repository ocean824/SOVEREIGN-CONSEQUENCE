# SOVEREIGN CONSEQUENCE

Grand-strategy/RTS morality and influence game where military, civic, economic and ideological decisions reshape a nation and its relationships rather than collapsing into a binary morality meter.

## Unreal foundation
Narrative Pro 2 + Ultra Game Template 1.3; RTS/RPG Unit Template; OverCrowd Massive Modular Crowds; Squad & Team Combat AI; Building System Multiplayer; HKH Attribute where useful; Mech Squad/other unit assets for prototyping; Element systems only if canonical warfare/world systems use them.

## Gates
V1: one theater/nation scenario with base/economy, units, influence/consequence model and campaign choices. V2: full strategic campaign, diplomacy/factions, civilian/crowd simulation, multiple doctrines. V3: creator/Forge mode, multiplayer if approved, persistent simulations and AXIOM/PYRAMID edition.
