# SOVEREIGN CONSEQUENCE — Game Design Bible

## Identity
Grand-strategy/RTS hybrid where national power, warfare, economy, diplomacy and morality create systemic consequences. Player choices reshape institutions/populations rather than merely filling a good/evil meter.

## Core loop
Set national priorities → allocate resources/research → build/deploy → diplomacy/intelligence → tactical/RTS conflict or crisis → population/faction reaction → institutional/moral consequences → adapt strategy.

## Strategic layer
Territory, resources, production, population, factions, legitimacy, diplomacy, research, intelligence, infrastructure and national influence. Systems must expose cause/effect sufficiently for players to reason about outcomes.

## RTS layer
Units/squads, formations, objectives, cover/terrain, logistics/reinforcement and commander abilities. RTS/RPG Unit Template + Squad & Team Combat AI accelerate Unreal prototype. Building System supports construction where compatible.

## Population/crowds
OverCrowd can accelerate visual/crowd simulation, but canonical population simulation is data-driven and need not simulate every citizen as an actor.

## Morality/consequence
Actions affect groups differently, creating tradeoffs, trust, resistance, radicalization, migration, economic behavior and diplomatic response. Avoid simplistic universal morality scoring.

## Forge/editor
Later scenario/map/rules editor with validation and shareable configurations. User content cannot bypass security/network policies.

## V1→V3
V1 proves one theater/nation pair, economy/diplomacy/consequence and RTS battles. V2 expands nations, AI diplomacy, scenarios and multiplayer. V3 global-scale campaign, mature editor/community systems and AXIOM-native implementation.
